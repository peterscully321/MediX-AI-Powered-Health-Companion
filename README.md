## What this repo contains
- `backend/` — FastAPI minimal demo server with endpoints:
  - POST /api/upload-prescription  (file upload → mock OCR parse)
  - GET  /api/prescription/{id}
  - POST /api/schedule-reminder
  - GET  /api/reminders
  - POST /api/confirm-dose
  - POST /api/chat
- `frontend/` — Minimal React app with Upload and Dashboard components (demo only).

## How to run (locally)
1. Backend:
   - `cd backend`
   - Create a Python virtualenv, install requirements: `pip install -r requirements.txt`
   - Run: `python app.py`
   - API runs at `http://localhost:8000`

2. Frontend (very small demo):
   - `cd frontend`
   - `npm install`
   - `npm start`
   - Open `http://localhost:3000` (adjust as needed). The frontend expects the backend at http://localhost:8000.
